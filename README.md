# NEXORA AI

منصة ذكاء اصطناعي مستقلة متعددة الوحدات. هذا المستودع مستقل تماماً عن OSAMIND وSmart Lab OS.

## الحالة
تم إصلاح بنية Next.js App Router وإضافة واجهة محادثة أولية وواجهة API آمنة تعمل على الخادم. بقية وحدات الوكيل والذاكرة والبحث والصوت والأتمتة ما زالت ضمن خارطة التطوير.

## المتطلبات والتشغيل
- Node.js 20.9 أو أحدث
- `npm install`
- انسخ `.env.example` إلى `.env.local` وضع مفتاح API في الملف المحلي فقط.
- `npm run dev` ثم افتح `http://localhost:3000`.

## البناء
`npm run build`

## إعداد الذكاء الاصطناعي
أضف `OPENAI_API_KEY` كمتغير بيئة سري في منصة الاستضافة. لا تضع المفتاح في الواجهة أو Git. يمكن اختيار النموذج عبر `OPENAI_MODEL`، والافتراضي `gpt-4o-mini`.

## البنية الحالية
- `app/page.tsx`: الواجهة العربية التفاعلية.
- `app/api/chat/route.ts`: وسيط المحادثة على الخادم.
- `app/layout.tsx`: تخطيط Next.js العام.
- `app/globals.css`: التنسيقات.

## مبادئ الأمان
- مفاتيح المزود تبقى على الخادم فقط.
- حد أقصى لطول رسالة المستخدم مع التحقق من الإدخال.
- مهلة زمنية للاتصال بمزود الذكاء الاصطناعي.
- لا ينفذ التطبيق تعليمات أو إجراءات خارجية من تلقاء نفسه.
