# NEXORA AI

منصة ذكاء اصطناعي مستقلة متعددة الوحدات. هذا المستودع جديد ولا يعتمد على OSAMIND أو Smart Lab OS.

## الحالة
مرحلة التأسيس الهندسي (Foundation). الواجهة الحالية نقطة انطلاق قابلة للتشغيل وليست منتجًا مكتملًا.

## المتطلبات
- Node.js 20.9 أو أحدث
- npm

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح http://localhost:3000

## المبادئ
- لا تضع مفاتيح API في الواجهة أو Git.
- لا تنفذ كودًا يرسله المستخدم على الخادم الرئيسي.
- جميع عمليات الوكيل الحساسة تتطلب صلاحيات وموافقة واضحة.
- لا تُجرى تغييرات على مستودعات المشاريع الأخرى.

## خارطة الطريق
1. Foundation + واجهة عربية RTL.
2. مصادقة وإدارة جلسات.
3. طبقة موحدة لمزودي الذكاء الاصطناعي.
4. ذاكرة ومصادر معرفة.
5. محرك وكيل بأدوات وصلاحيات.
6. مساحة ملفات واستوديو برمجة مع بيئة تنفيذ معزولة.
7. البحث والصوت والأتمتة.
8. التخزين السحابي والعمل دون اتصال والمزامنة.
9. اختبارات أمنية وتشغيلية ثم النشر.

## البنية المبدئية
- `src/app`: صفحات التطبيق.
- `src/components`: مكونات الواجهة.
- `src/lib`: وظائف مشتركة.
- `docs`: القرارات الهندسية وخطة العمل.
