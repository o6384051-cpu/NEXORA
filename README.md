# NEXORA AI

منصة ذكاء اصطناعي مستقلة. هذا المستودع منفصل تماماً عن OSAMIND وSmart Lab OS.

## ما أضيف في أساس المنصة
- محول مزودي ذكاء اصطناعي: OpenAI وGoogle Gemini وAnthropic، مع اختيار المزود من إعداد الخادم.
- فريق وكلاء أولي: تخطيط، بحث، هندسة، مراجعة، وتنظيم التنفيذ.
- نقطة بحث ويب عبر Tavily.
- تحليل ملفات نصية وMarkdown وCSV وJSON حتى 2MB.
- تكامل أولي لتوليد الفيديو ومتابعة حالة المهمة عبر Replicate.
- تخزين وجدولة مهام عبر Upstash Redis وتشغيل مجدول عبر Vercel Cron.
- نقطة نشر Vercel لمستودعات GitHub، محمية بسر إجراء خاص.
- مساحة أدوات على `/workspace`.
- manifest وservice worker لأساس PWA قابل للتثبيت على Android.

## ما لا يزال يحتاج استكمالاً
- لا توجد مصادقة مستخدمين أو إدارة جلسات/صلاحيات كاملة بعد؛ إجراءات الفيديو والنشر والجدولة محمية وتتطلب طبقة جلسات آمنة قبل فتحها للمستخدمين.
- GitHub App موجود كإعداد جاهزية فقط؛ عمليات قراءة/كتابة المستودعات وفتح PR تحتاج استكمال OAuth/App installation وربطها بهوية المستخدم.
- فريق الوكلاء الحالي ينسق استدعاءات نصية متتابعة؛ لا يشغل شيفرة أو أوامر نظام ولا يملك أدوات خارجية تلقائية.
- البحث يحتاج TAVILY_API_KEY.
- تحليل الملفات يدعم حالياً النصوص فقط؛ PDF وDOCX وXLSX غير مفعلة بعد.
- الفيديو يحتاج حساب Replicate وموديل مدعوم ومفتاحاً.
- المهام المجدولة تحتاج Upstash وVercel Cron؛ التنفيذ يحدث في وقت Cron المجدول، وليس فوراً.
- الصوت الحالي في المتصفح هو إدخال كلام وقراءة صوتية أساسية؛ المحادثة الصوتية الحية ثنائية الاتجاه غير مكتملة.
- PWA ليس تطبيق Android أصلياً ولا ملف APK؛ يلزم مشروع Android/Capacitor أو React Native واختبار بناء وتوقيع.
- إنشاء تطبيقات ومواقع من وصف المستخدم، sandbox آمن، اختبارات، ومراحل نشر تلقائية ما زالت تحتاج بناء.

## التشغيل
- Node.js 20.9+
- `npm install`
- إعداد المتغيرات السرية في `.env.local` محلياً أو منصة الاستضافة.
- `npm run dev`
- `npm run build`

## متغيرات البيئة
راجع `.env.example`. لا تضع مفاتيح API أو مفاتيح GitHub أو Vercel في ملفات عامة أو في واجهة المتصفح.

## ملاحظات الأمان
- لا تفتح إجراءات النشر والمهام والفيديو قبل إضافة مصادقة المستخدمين وإدارة الأدوار.
- إعداد تسجيل الدخول: اضبط NEXORA_ADMIN_PASSWORD وNEXORA_SESSION_SECRET ثم سجّل الدخول عبر /login.\n- إجراءات النشر والفيديو والمهام والذكاء الاصطناعي تتطلب جلسة المسؤول.\n- مفاتيح المزودات تبقى على الخادم.
- المخرجات المولدة غير موثوقة ويجب عزل تنفيذ الشيفرة في sandbox مستقل قبل توفير قدرات تشغيل فعلية.
