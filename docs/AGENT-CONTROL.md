# إدارة فريق وكلاء NEXORA

## تجربة المستخدم
يتعامل المستخدم مع NEXORA من خلال واجهة واحدة وإجابة نهائية واحدة. لا تُعرض أصوات الوكلاء أو أسباب تصويتهم أو نقاشاتهم الداخلية.

## تحكم المؤسس
تظهر إعدادات الفريق داخل مساحة العمل بعد تسجيل دخول المسؤول:
- تشغيل أو إيقاف الفريق بالكامل.
- تشغيل أو إيقاف التخطيط والبحث والهندسة والمراجعة والتنفيذ بشكل مستقل.
- تُطبّق الإعدادات على طلبات الوكلاء والمهام المجدولة.

## التخزين
تُحفظ الإعدادات في Upstash Redis تحت المفتاح `nexora:agent-settings`.
يجب ضبط المتغيرين التاليين في بيئة الخادم:
- `UPSTASH_REDIS_REST_URL`
- `UPSTASH_REDIS_REST_TOKEN`

إذا لم تتوفر بيانات Redis، تعمل الإعدادات الافتراضية (كل الأدوار مفعلة) للقراءة فقط، ويظهر للمسؤول تنبيه بأن الحفظ الدائم غير مضبوط.

## السلامة
- واجهة التحكم وواجهات القراءة/الحفظ محمية بجلسة المسؤول.
- تعطيل الفريق بالكامل يمنع استدعاء نماذج الوكلاء لهذه المهمة.
- تعطيل دور منفرد يمنع تشغيله ويستبعد مخرجاته من التجميع.
- لا يعني اكتمال التحليل أن كوداً قد نُفذ أو تطبيقاً قد نُشر.
